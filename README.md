# Zentry: O Metagame Layer Criativo 🚀

Bem-vindo ao **Zentry**, uma experiência interativa e inovadora que redefine o universo de games! Este projeto explora a ideia de um metagame layer — um ecossistema onde produtos e comunidades se conectam para transformar sua vida em uma aventura épica, misturando experiências de Web2 e Web3.

## ✨ Visão Geral

Entre no Metagame Layer e libere o poder da Play Economy. Zentry propõe unir jogadores, plataformas e universos, criando uma sobreposição gamificada sobre o seu mundo, onde cada atividade vira um passo em uma grande jornada.

---

## 🕹️ Funcionalidades Principais

- **radia<b>n</b>t**: App metagame cross-plataforma. Suas atividades em jogos Web2/Web3 viram recompensas e conquistas em uma aventura contínua.
- **zig<b>m</b>a**: Coleção NFT inspirada em anime e games, pronta para expansão de propriedade intelectual.
- **n<b>e</b>xus**: Hub social gamificado, transformando interação em comunidade Web3 em diversão e competição.
- **az<b>u</b>l**: Agente de IA que eleva sua gameplay — mais produtiva, mais divertida.
- **E mais em breve!**

## 🌍 Sobre

> “The Game of Games begins — your life, now an epic MMORPG.”

O Zentry une jogadores de incontáveis jogos e plataformas. Descubra a maior aventura compartilhada do mundo! Aqui, cada usuário é protagonista de uma saga única.

---

## 🎬 Experiência Imersiva

O projeto aposta em vídeos, animações e navegação dinâmica para criar um portal visualmente marcante. Elementos como *Hero Section* e *Bento Cards* destacam produtos e novidades. Você pode assistir trailers, navegar por hubs sociais e explorar funcionalidades interativas.

---

## 💡 Stack Tecnológica

- **React + Vite** para performance e desenvolvimento ágil;
- **GSAP** para animações de alto impacto;
- **React Icons** e componentes customizados para UI moderna;
- **Integração multimídia** (vídeos, áudio e imagens interativas).

## 📲 Como Rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/GeovanniJDA/awwwards.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Rode o projeto:
   ```bash
   npm run dev
   ```
4. Acesse [http://localhost:5173](http://localhost:5173) no navegador.
